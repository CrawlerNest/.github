# CrawlerNest

**One warehouse for global university rankings from QS, THE and ARWU, with the limits of the data stated.**

CrawlerNest builds data infrastructure for university rankings: crawling the major ranking sources, resolving them to canonical institutions, and serving the result with its sources, coverage and confidence made explicit rather than hidden.

## What we work on

| Area | Focus |
|---|---|
| Data pipelines | Multi-source ranking ingestion, entity resolution, staging to warehouse |
| Analytics | Cross-source comparison, rank movement, data quality diagnostics |
| Modelling | Explainable models over published ranking indicators |
| Web platform | Browsing, comparing and saving universities |

## Principles

**Honest data.** A missing rank is reported as our gap, not hidden. Estimates are labelled as estimates.

**Reproducible.** Every number can be traced back to the source and edition it came from.

**Polite crawling.** We respect each source's terms and rate limits. Ranking data belongs to its publishers.
